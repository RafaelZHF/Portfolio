Atur teks & foto situs

Field di bawah mencerminkan persis struktur assets/js/content.js, dikelompokkan per section, ditambah satu field foto (avatar chat widget). Ubah field apa saja, cek hasilnya di panel pratinjau di kanan, lalu klik Simpan di bawah (atau Apply Changes di pojok kanan atas) — situs live langsung berubah dalam hitungan detik, tanpa perlu commit atau push apa pun.

Foto (Avatar Chat Widget)

Belum ada foto baru dipilih

Dipakai sebagai foto avatar di widget chat mengambang (kiri bawah situs). Disimpan sebagai file gambar biasa (PNG/JPG/ WEBP/GIF), maksimal sekitar 1.5MB. Foto baru langsung aktif setelah kamu klik Simpan / Apply Changes.

Katalog Produk (Shop)

Produk di bawah tampil di halaman /shop/. Belum bisa diklik pengunjung (pembayaran menyusul) — untuk saat ini cukup nama, harga, dan foto produk saja yang tampil di katalog.
