UI Settings

Atur semua teks yang tampil di situs utama, dikelompokkan per bagian, ditambah foto avatar widget chat. Field di bawah mencerminkan persis struktur assets/js/content.js. Ubah field apa saja lalu klik Apply Changes di pojok kanan atas — situs live langsung berubah dalam hitungan detik, tanpa commit atau push apa pun.
